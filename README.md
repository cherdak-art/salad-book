# Мои салаты — сборка APK

Это Android-обёртка над приложением `index.html` (лежит в `app/src/main/assets/`).
Данные хранятся на телефоне внутри приложения.

## Как получить APK (один раз, около 15 минут)

1. Установите **Android Studio** с developer.android.com/studio (бесплатно).
2. Откройте Android Studio → **Open** → выберите папку `SaladBook`.
3. Дождитесь окончания загрузки (Gradle Sync). При первом запуске Studio сама
   докачает Android SDK и согласится на нужные лицензии.
4. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Когда появится уведомление, нажмите **locate**. Файл:
   `app/build/outputs/apk/debug/app-debug.apk`
6. Перенесите файл на телефон (USB, Telegram «Избранное», почта, Google Drive).
7. На телефоне откройте файл. Android спросит разрешение на установку из
   неизвестных источников: разрешите для приложения, которым открываете файл.
8. Нажмите «Установить» и откройте приложение «Мои салаты».

Это debug-сборка. Для личного использования её достаточно, в Google Play её
загружать не нужно. Подписывать ключом не требуется.

## Обновление рецептов в приложении

Если позже поменяется сам интерфейс (файл `index.html`), замените
`app/src/main/assets/index.html` и заново соберите APK. Рецепты при этом
сохранятся, если не переустанавливать приложение с удалением данных.

## Резервная копия

- **Экспорт** на главном экране открывает меню «Поделиться». Отправьте копию
  себе в Telegram или на почту и сохраните.
- **Импорт** — вставьте текст копии в появившееся окно.

Удаление приложения удаляет все рецепты. Делайте экспорт перед переустановкой.
