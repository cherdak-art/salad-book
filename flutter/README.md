# Ладушки салаты (Flutter)

Личное приложение для повара: база салатов в Supabase, расчёт продуктов на порцию 100 г.

## Сборка

Сборка идёт в GitHub Actions (файл `.github/workflows/build.yml`):
1. Откройте вкладку **Actions** в репозитории.
2. Дождитесь зелёной галочки у последнего запуска.
3. Скачайте артефакт `ladushki-apk` и установите `app-release.apk` на телефон.

## Структура

- `lib/data/repo.dart` — запросы к Supabase
- `lib/state/app_state.dart` — вход, список, экспорт и импорт
- `lib/screens/` — экраны: вход, список, рецепт, редактирование
- `lib/widgets/` — плитки и анимации
- `lib/theme.dart` — цвета: тёмная основа, коричневый и янтарный из логотипа

## Ограничения

Не тестировалось на устройстве: сначала проверьте сборку и вход.
